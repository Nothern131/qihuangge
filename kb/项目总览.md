# 岐黄阁 · 项目总览（知识库中心版）

> 最后更新：2026-08-06

## 项目简介
岐黄阁是一个纯前端中医药古籍知识推理系统，集成辨证推理、方剂解析、本草查询、体质辨识、大师蒸馏、药膳食谱等核心功能，所有算法本地运行，零 API 调用。

## 技术架构（7 层）

| 层级 | 内容 |
|------|------|
| 第1层·用户入口 | index.html 首页 + 导航 |
| 第2层·路由分发 | app.js · Hash 路由 |
| 第3层·组件层 | 6个功能组件 + 大师蒸馏 |
| 第4层·引擎层 | EngineRegistry 统一注册：辨证/方剂/本草/体质/大师 |
| 第5层·古籍知识库 | ancient_texts.json（50+条核心条文） |
| 第6层·药膳食谱库 | 九种体质·食疗方案 |
| 第7层·大师蒸馏 & 输出 | 12位中医药大师风格复刻 · 五段式分析 |

## 技术特点

- 纯前端算法，零 API 调用
- IIFE 模块化架构
- EngineRegistry 统一注册机制
- 五段式大师蒸馏（开篇→总论→论治→经典引用→结语）
- 严谨的医学免责声明
- 古典中医风格 UI（宣纸色+墨色+朱砂红）
- 响应式设计（桌面端+移动端）
