# 岐黄阁 · 中医药古籍知识推理系统

纯前端中医药知识推理系统，零后端依赖，支持 GitHub Pages 部署。

## 功能模块

| 模块 | 说明 |
|------|------|
| 🔮 辨证推理 | 八纲辨证 + 六经辨证 + 脏腑辨证，三路并行推理 |
| 📜 方剂解析 | 君臣佐使拆解、配伍规律、随证加减、煎服法 |
| 🌿 本草查询 | 22味常用中药，含古籍原文引用 |
| 🧬 体质辨识 | 九种体质问卷，实时症状关联高亮 |
| 👨‍⚕️ 大师蒸馏 | 6位医家风格复刻，五段式解读 |
| 🍲 药膳食谱 | 33道药膳，古籍溯源标注 |
| 👤 用户档案 | 历史记录追溯、趋势分析、体验链接分享 |

## 技术架构

- **前端**：原生 HTML / CSS / JavaScript，零框架依赖
- **数据存储**：localStorage（按用户隔离）
- **路由**：Hash 模式（`#/home`），兼容 GitHub Pages
- **部署**：纯静态站点，支持 GitHub Pages / Vercel / Netlify

## 快速开始

### 本地运行

```bash
cd e:\岐黄阁
python -m http.server 8892 --bind 127.0.0.1
# 访问 http://127.0.0.1:8892
```

### GitHub Pages 部署

详见 [DEPLOY.md](DEPLOY.md)

## 体验链接

生成分享链接：用户档案 → 选择档案 → 「🔗 生成分享链接」

他人打开链接后自动加载完整存档数据，可继续测试，新数据独立存储。
