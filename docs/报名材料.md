## 三、作品详细介绍（对应表单第 12 题）

### 1、核心功能与亮点

```
岐黄阁是一个纯前端的中医药知识助手，目前实现了 7 个模块：

体质辨识：九种体质问卷，答题过程中实时高亮关联症状，结束后给出体质倾向和知识解释；
辨证推理：八纲、六经、脏腑三路并行展示，结果定位为知识参考，并提示有不适及时就医；
方剂解析：按君臣佐使拆解方剂组成，展示配伍规律、随证加减和煎服法；
本草查询：收录 80 味常用中药，每条附古籍原文出处；
药膳与医家：33 道药膳标注古籍溯源，12 位医家按五段式做风格化解读；
用户档案：测评和查询记录保存在浏览器本地，可以回看历史、查看趋势，也能生成分享链接给他人体验；
合规提示：首页和结果页统一展示免责声明与就医提示。

相比原来翻书或在不同网页之间跳转，岐黄阁把体质了解、知识查阅和记录收进了一条流程：用户从测评开始，看到体质倾向和对应知识，再把这次结果存进档案，下次可以直接对比。全部数据只存在本地，不需要注册账号。
```
