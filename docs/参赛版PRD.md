## 2. 产品定位与赛道

**一句话定位**：面向中医药爱好者的私人健康助手，记录体质变化、理解古籍知识、整理就医前的问题。

| 项 | 决策 |
|---|---|
| 主赛道 | 学习生活（生活记录 / 个人成长辅助） |
| 对应专项奖 | 生活有解奖（2000 元） |
| 定位关键词 | 健康记录、知识学习、就医准备 |
| 明确不宣称 | 诊断、治疗、处方、疗效、替代医师 |

## 3. 目标用户与核心任务

| 项 | 定义 |
|---|---|
| 主要用户 | 关注日常调理与中医药文化的普通用户，非执业医师 |
| 次要用户 | 中医学习者、需要整理就诊问题的用户 |
| 触发 | 想了解自己的体质倾向，或想记录一次身体状态 |
| 核心任务 | 体质测评 → 结果解读 → 保存档案 → 下次复访对比 |
| 完成条件 | 用户独立完成测评，看到体质倾向与知识解释，档案中可查历史记录 |
| 信任基础 | 古籍原文可溯源；结论标注"仅供知识参考"；提供就医提示 |

## 5. 核心演示链路（评委 5 分钟）

1. 打开首页，首屏看到定位、7 个模块入口、免责声明。
2. 进入体质辨识，完成 9 种体质问卷，得到体质倾向与关联症状说明。
3. 进入辨证推理，展示八纲 / 六经 / 脏腑三路结果，强调"知识参考"标签。
4. 打开方剂解析或本草查询，展示古籍原文出处。
5. 回到用户档案，展示本次记录已保存，可查看历史与趋势。
6. 说明 TRAE 实践：3 个关键任务与截图。

每个模块正文按：目的 / 触发 / 处理规则 / 结果与状态 / 异常展开。

## 7. 共享规则

- 数据存储：全部 localStorage，不上传服务端，不做账号体系。
- 刷新与重进：档案数据不丢失；清空浏览器数据即清空档案。
- 结果口径：所有个性化结论统一标注"知识参考，不构成诊断或治疗建议"。
- 古籍引用：保留原文与出处，不改写原文含义。
- 分享链接：分享的是存档快照，新数据独立存储，不影响原档案。
